# Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game created using HTML, CSS, and JavaScript. The player can choose Rock, Paper, or Scissors and compete against a randomly generated computer choice.

## Features

- Choose between Rock, Paper, and Scissors
- Random computer move generation
- Displays whether the player wins, loses, or ties
- Keeps track of wins, losses, and ties
- Saves the score using localStorage
- Reset Score button
- Custom Rock, Paper, and Scissors images
- Simple dark-themed interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. The player selects Rock, Paper, or Scissors.
2. JavaScript randomly selects a move for the computer.
3. The player's move is compared with the computer's move.
4. The game displays the result.
5. Wins, losses, and ties are automatically updated.
6. The score is saved in the browser using localStorage.
7. The player can reset the score at any time.

## Project Files

- `rock-paper-scissors.html` - Contains the structure of the game.
- `rock-paper-scissors.css` - Controls the design and appearance.
- `rock-paper-scissors.js` - Contains the game logic and score system.
- `rock-emoji.png` - Rock image.
- `paper-emoji.png` - Paper image.
- `scissors-emoji.png` - Scissors image.
